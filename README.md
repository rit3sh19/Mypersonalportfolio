# rit3sh19 — Developer Portfolio

A curated portfolio built with React, TypeScript, and Vite. Project content lives
in [`data/projects.ts`](./data/projects.ts), separate from the UI; the repository
audit and evidence notes live in [`data/project-research.md`](./data/project-research.md).

## Run locally

```bash
npm install
npm run dev
```

## Validate and build

```bash
npm run typecheck
npm run build
```

Project previews are original illustrative UI sketches, not screenshots or
claims about working product deployments. Live-demo links are only shown when
one has been verified.
